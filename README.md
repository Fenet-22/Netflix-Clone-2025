# 🎬 Netflix Clone 2025

A high-performance, fully responsive Netflix front-end clone. This project demonstrates the ability to handle real-world API data, manage complex React states, and create a seamless user experience that mimics the world's most popular streaming service.

## 🚀 Live Demo

**Check out the live project here:** [https://netflix-clone-2025-7q6z.vercel.app/](https://netflix-clone-2025-7q6z.vercel.app/)

---

## ✨ Key Features

- **Dynamic Hero Banner:** Automatically selects a featured "Netflix Original" from the database on every refresh.
- **Smart Header:** A navigation bar that detects scrolling and transitions from transparent to solid black, just like the real Netflix UI.
- **Trailer Playback:** Integrated with YouTube to allow users to click any movie poster and instantly watch the official trailer.
- **Categorized Movie Rows:** Organized sections for Trending, Top Rated, Action, Comedy, Horror, Romance, and Documentaries.
- **Fully Responsive:** Optimized for desktop, tablets, and mobile screens.

---

## 🛠️ The Materials (Tech Stack)

This project was built using a professional modern development workflow:

- **React.js & Vite:** The core engine used for building a fast and scalable user interface.
- **Axios:** The "delivery service" used to fetch movie data from external servers.
- **TMDB API:** The source of all movie data, images, and descriptions.
- **Material UI (MUI):** Professional iconography for search, notifications, and navigation.
- **React-YouTube & Movie-Trailer:** A powerful combination used to find and play movie trailers dynamically.

## 🏗️ How to Run This Project Locally

If you want to run this project on your own machine, follow these simple steps:

### 1. Prerequisites

Ensure you have **Node.js** installed (Version 16 or higher).

### 2. Clone the Repository

Open your terminal or Git Bash and run:

```bash
git clone [https://github.com/Fenet-22/Netflix-Clone-2025.git](https://github.com/Fenet-22/Netflix-Clone-2025.git)
cd Netflix-Clone-2025
```
